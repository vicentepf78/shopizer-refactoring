# ADR-004: Contratos PaymentModuleV2 e ShippingQuoteModuleV2 da Onda 3

## Status

Aceito

## Data

2026-07-26

## Contexto

`PaymentModule` e `ShippingQuoteModule` atuais em `sm-core-modules` aceitam entidades JPA (`Order`, `Customer`, `ShoppingCartItem`, `MerchantStore`) — acoplamento MODEL disfarçado de plugins (plano mestre §6.7). A Onda 3 entrega contratos V2 baseados em DTO e snapshots (`OrderSnapshot`, `CustomerSnapshot`, etc.) sem implantar novos microsserviços.

## Decisão

A Onda 5 **depende dos entregáveis da Onda 3** `PaymentModuleV2` e `ShippingQuoteModuleV2` em `sm-core-modules`, mais snapshots DTO em `shopizer-api-contracts`. `integration-service` invoca interfaces V2 em runtime. Plugins V1 legados são ponteados via `PaymentModuleV2Adapter` / `ShippingQuoteModuleV2Adapter` (ponytail: remover quando todos os plugins implementarem V2 nativamente).

## Alternativas consideradas

### Alternativa 1: Redesenhar contratos dentro da Onda 5

- **Prós:** Onda autocontida.
- **Contras:** Duplica escopo Onda 3; plano mestre atribui explicitamente redesign de contratos à Onda 3.
- **Rejeitada:** Ordem de pré-requisitos é fixa.

### Alternativa 2: Manter contratos V1 com entidades em integration-service

- **Prós:** Menos código de adaptador.
- **Contras:** Força `sm-core-model` e grafo Order em integration-service; falha no objetivo stateless.
- **Rejeitada:** Contradiz estratégia de decomposição.

### Alternativa 3: Contratos somente OpenAPI sem atualização sm-core-modules

- **Prós:** Plugins HTTP-first.
- **Contras:** Quebra padrão de módulo publicável Maven Central; 8+ implementações Java de plugin no repositório.
- **Rejeitada:** Registry in-process (ADR-005) exige interfaces Java.

## Consequências

### Positivas

- Execute Onda 5 bloqueado até contratos existirem — força sequenciamento correto.
- `sm-core-modules` publicável permanece fronteira de integration para starters de pagamento externos.

### Negativas

- Manutenção de adaptadores até plugins migrarem.
- Atraso Onda 3 bloqueia calendário Onda 5 diretamente.
