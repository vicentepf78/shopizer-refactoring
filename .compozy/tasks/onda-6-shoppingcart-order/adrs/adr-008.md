# ADR-008: Feature flags and rollback plan

## Status

Accepted

## Date

2026-07-26

## Context

Onda 6 is the highest-risk wave (order 9/10). Production cutover requires independent rollback for cart, order reads, and saga checkout without redeploying services.

## Decision

Three **independent boolean flags** (Spring properties):

| Property | Default | Effect when false |
|----------|---------|-------------------|
| `wave6.shoppingcart.strangler.enabled` | `false` | Cart in-process via legacy facade |
| `wave6.order.strangler.enabled` | `false` | Order read/write in-process |
| `wave6.checkout.saga.enabled` | `false` | Legacy `orderService.processOrder` |

Supporting flag:

| Property | Default | Effect |
|----------|---------|--------|
| `wave6.totals.http.enabled` | `false` | Cart totals via HTTP vs in-process (enable before SC-ready) |

**Rollback procedure:**

1. Set failing flag to `false` in config / k8s ConfigMap
2. Rolling restart sm-shop pods (< 5 min target)
3. Wave 6 services may remain running (idle) — no mandatory scale-down
4. Verify legacy path via smoke test script `scripts/wave6-rollback-drill.sh`

**Canary:** Enable saga for 5% traffic via header `X-Wave6-Canary: true` (optional implementation in T32 — if omitted, environment-level staging canary only).

## Alternatives considered

### Single master flag

- **Pros:** One switch.
- **Cons:** Cannot roll back checkout without disabling cart remote.
- **Rejected.**

### Blue/green deploy only

- **Pros:** Infrastructure standard.
- **Cons:** Does not help partial feature rollback mid-incident.
- **Rejected as sole mechanism** — combine with flags.

## Consequences

**Positive:** Blast radius control; ops-friendly; aligns with wave1/wave2 strangler pattern.

**Negative:** Flag combinatorics (8 states) — document allowed production states in runbook (only 4 valid combos).

## Valid production states

| cart | order | saga | Meaning |
|------|-------|------|---------|
| false | false | false | Full legacy (default) |
| true | false | false | Remote cart only |
| true | true | false | Remote cart + order read |
| true | true | true | Full Wave 6 |
