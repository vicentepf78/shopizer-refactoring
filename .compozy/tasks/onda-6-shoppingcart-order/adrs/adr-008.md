# ADR-008: Feature flags e plano de rollback

## Status

Aceito

## Data

2026-07-26

## Contexto

A Onda 6 é a onda de maior risco (order 9/10). Cutover em produção exige rollback independente para cart, leituras de order e saga checkout sem redeploy de serviços.

## Decisão

Três **flags booleanas independentes** (properties Spring):

| Property | Default | Efeito quando false |
|----------|---------|-------------------|
| `wave6.shoppingcart.strangler.enabled` | `false` | Cart in-process via facade legada |
| `wave6.order.strangler.enabled` | `false` | Leitura/escrita order in-process |
| `wave6.checkout.saga.enabled` | `false` | `orderService.processOrder` legado |

Flag de suporte:

| Property | Default | Efeito |
|----------|---------|--------|
| `wave6.totals.http.enabled` | `false` | Totais cart via HTTP vs in-process (habilitar antes de SC-ready) |

**Procedimento de rollback:**

1. Definir flag com falha como `false` em config / k8s ConfigMap
2. Rolling restart pods sm-shop (meta < 5 min)
3. Serviços Wave 6 podem permanecer rodando (ociosos) — sem scale-down obrigatório
4. Verificar caminho legado via script smoke test `scripts/wave6-rollback-drill.sh`

**Canary:** Habilitar saga para 5% do tráfego via header `X-Wave6-Canary: true` (implementação opcional em T32 — se omitida, canary staging somente por ambiente).

## Alternativas consideradas

### Flag master única

- **Prós:** Um interruptor.
- **Contras:** Não pode reverter checkout sem desabilitar cart remoto.
- **Rejeitada.**

### Somente deploy blue/green

- **Prós:** Padrão de infraestrutura.
- **Contras:** Não ajuda rollback parcial de feature mid-incident.
- **Rejeitada como mecanismo único** — combinar com flags.

## Consequências

**Positivas:** Controle de blast radius; amigável a ops; alinha com padrão strangler wave1/wave2.

**Negativas:** Combinatória de flags (8 estados) — documentar estados de produção permitidos no runbook (somente 4 combos válidos).

## Estados de produção válidos

| cart | order | saga | Significado |
|------|-------|------|---------|
| false | false | false | Legado completo (default) |
| true | false | false | Somente cart remoto |
| true | true | false | Cart remoto + order read |
| true | true | true | Onda 6 completa |
